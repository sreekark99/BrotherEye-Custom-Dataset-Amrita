# Custom Amrita Dataset – BrotherEye Project

## About the Dataset

The **Custom Amrita Dataset** is a collection of classroom images developed as part of the **BrotherEye Project**.

This dataset is intended for training and evaluating a Computer Vision (CV)-based intelligent system designed to identify potential malpractice and suspicious activities during classroom examinations.

The images represent real-world classroom examination scenarios and serve as training data to support the development of automated examination monitoring and malpractice identification systems.

## Dataset Availability

This repository contains a **subset of the complete Custom Amrita Dataset**. Not all images have been made publicly available in this repository.

## Intended Use

The dataset is intended primarily for:

- Academic and research purposes.
- Computer Vision and deep learning model development.
- Classroom examination monitoring research.
- Detection and identification of potential examination malpractice.
